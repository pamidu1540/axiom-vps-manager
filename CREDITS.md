## Open-Source Libraries & Upstream Tools

### Networking & VPN Core
- **[sing-box](https://github.com/SagerNet/sing-box)** (SagerNet) — Universal proxy platform supporting VLESS, Reality, Shadowsocks, Trojan, Hysteria2, TUIC, and WireGuard.
- **[Xray-core](https://github.com/XTLS/Xray-core)** (XTLS Project) — Advanced VLESS, VMess, and XTLS/REALITY protocol suite.
- **[Hysteria 2](https://github.com/apernet/hysteria)** (apernet) — High-throughput, QUIC-based censorship-resistant proxy.
- **[WireGuard](https://www.wireguard.com/)** (Jason A. Donenfeld) — Fast, modern, and secure kernel VPN.
- **[OpenVPN](https://openvpn.net/)** & **[Easy-RSA](https://github.com/OpenVPN/easy-rsa)** — SSL/TLS VPN and Public Key Infrastructure.
- **[BadVPN / badvpn-udpgw](https://github.com/nickoala/badvpn)** (Ambroz Bizjak) — UDP gateway for VoIP and gaming over TCP SSH tunnels.

### Web Server & Reverse Proxy
- **[Caddy Web Server](https://caddyserver.com/)** (Matthew Holt & Caddy Authors) — Modern, memory-safe reverse proxy with automatic HTTPS and HTTP/3 support.

### Telegram Automation
- **[python-telegram-bot](https://python-telegram-bot.org/)** — Asynchronous Python framework for the Telegram Bot API.
- **[ShellBot](https://github.com/shellscriptx/shellbot)** (Juliano Santos) — Unofficial Bash Telegram Bot API wrapper used in legacy versions.

### Security, System & Utility Tools
- **[nftables / Netfilter](https://netfilter.org/)** — Modern kernel packet classification framework replacing legacy iptables.
- **[Fail2ban](https://www.fail2ban.org/)** — Intrusion prevention framework monitoring authentication logs.
- **[age encryption](https://age-encryption.org/)** (Filippo Valsorda) — Simple, modern, and secure file encryption.
- **[Rich](https://github.com/Textualize/rich)** & **[Textual](https://github.com/Textualize/textual)** (Will McGugan) — Terminal formatting and TUI framework.
- **[vnStat](https://humdi.net/vnstat/)** (Teemu Toivola) — Console-based network traffic monitor.
- **[jq](https://github.com/jqlang/jq)** — Lightweight command-line JSON processor.
